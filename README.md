# Personal Finance Tracker

An open-source, privacy-focused personal finance Progressive Web App (PWA) built with React, Tailwind CSS, and daisyUI.

## Overview

Personal Finance Tracker is a project to build a simple, accessible application for managing personal finances.

The project is developed in the open, starting from its initial foundations, with an emphasis on clean architecture, maintainability, testing, and user privacy.

## Goals

- Track income and expenses.
- Organize financial transactions and accounts.
- Create and manage budgets.
- Provide useful summaries of personal finances.
- Keep financial data private by default.
- Support installation and use as a Progressive Web App.

These are project goals; features are not necessarily implemented yet.

## Technology

- React
- TypeScript
- Tailwind CSS
- daisyUI
- Vite

## Project Status

**Early development.** The application is being built incrementally, starting with its foundations. Features and architecture may change as the project evolves.
